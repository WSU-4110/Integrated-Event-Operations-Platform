# FR-11 attendance corrections

FR-10 was merged in PR #78. This PR targets main and adds FR-11 attendance corrections. Check-in follows Remove/Restore: pending and approved registrations are active; waitlisted and declined registrations are removed.

An authorized organizer can reverse an accidental check-in after entering a nonblank reason (maximum 1000 characters). The server locks the event registration and checks its attendance version so a stale form cannot reverse a newer arrival. Clearing attendance and recording the original arrival time/organizer, reason, correcting organizer and correction time are one transaction. Failed corrections roll back both changes. Normal check-in increments the attendance version and requires an active status (pending or approved).

Duplicate check-in preserves and displays the existing arrival time. Reversal makes the participant eligible for another normal check-in if still active. Counts and filters reflect only current attendance; correction history is retained separately and available only to authorized organizers. Changing registration approval or Discord access is outside this correction action.
